# salto-youth-scraper
scraper voor Erasmus+ programma onderdelen specifiek voor Nederlandse deelnemers.

De bedoeling van deze python code is het verzamelen (scrapen) van data van de website www.salto-youth.net met als doel het verzamelen van specifieke programma onderdelen waar Nederlandse deelnemers aan mee kunnen doen, het hoort automatisch activiteiten te verzamelen waar de aanmeldingsperiode nog niet van verlopen is. is de aanmeld periode wel afgelopen dan zou die dit automatisch moeten verwijderen. dit zou in eerste instantie gedeeld worden op de website van ons collectief te vinden op www.dewikkel.nl de doelstelling is het makkelijker overzichtelijk en beschikbaar maken van openbare info zonder verdwaald te raken op de website van salto. op de website van salto en in hun juridische formulieren staat dat dit toegestaan is mits je de verzamelde activiteiten terug laat linken naar de officiële pagina dit gaan we dan ook doen. we pakken namelijk ook alleen de informatie die beschikbaar is op salto youth en gebruiken dit alleen ter versimpeling voor deelnemers uit Nederland en willen daarmee de bereikbaarheid voor deze deelnemers vergroten. deze github is daarom ook openbaar zodat andere organisaties dit zouden kunnen implementeren.
